# サッカー試合日程カレンダー（iCal自動配信）
### サッカー日本代表（SAMURAI BLUE） & J1 鹿島アントラーズ

JFA（公益財団法人 日本サッカー協会）公式サイトおよび Jリーグ公式データサイトから最新の試合日程を自動取得し、iCalendar形式（`.ics`）で配信・自動更新するリポジトリです。

iPhone（iOS）やMac、Googleカレンダーなどのカレンダーアプリに「照会（購読）」登録することで、**最新の試合日程、キックオフ時間、対戦相手、会場、放送情報、試合結果が常に自動で同期**されます。

---

## 🌟 特徴

- **常に最新情報を自動反映**: GitHub Actionsにより毎日1回（日本時間 深夜4:00）自動で公式サイト・データサイトを巡回・更新
- **正確なJST（日本時間）対応**: タイムゾーン `Asia/Tokyo`（VTIMEZONE）を明示し、時差ボケのない正確なスケジュールを配信
- **直感的なイベント表記**:
  - **ホーム・アウェイ一目瞭然**: 鹿島の試合はホーム戦が `【鹿島】vs 相手`、アウェイ戦が `【鹿島】@ 相手` と表記
  - **キックオフ時間・会場・TV放送も網羅**:
    - 時間発表済みの試合は正確な開始時刻〜終了時刻（2時間）をブロック
    - 時間未発表の試合は「終日イベント」として仮登録され、時間発表後に自動更新
    - 会場スタジアム名、対戦カード、スコア結果、TV中継・配信局、公式詳細ページURLも記載
- **相手サーバーへの負荷軽減**: リクエスト間隔（1秒スリープ）やアクセス頻度（1日1回）を厳密に制限し、適切なUser-Agentを設定したセーフ運用

## 📱 iPhone（iOSカレンダー）での登録手順

iPhoneの標準「カレンダー」アプリに登録すると、予定が自動更新されます。

### 方法A: ワンタップ追加（おすすめ）
1. iPhoneの **Safari** で上記の `webcal://...` URLを開きます。
2. 「このWebサイトは"カレンダー"を開こうとしています」と表示されたら「許可」をタップします。
3. 照会確認ダイアログが表示されたら「照会」をタップして完了です。

### 方法B: 設定アプリから手動追加
1. iPhoneの **「設定」** アプリを開きます。
2. **「カレンダー」** をタップします。  
   *(iOSのバージョンによっては「メール」または「パスワードとアカウント」>「アカウント」)*
3. **「アカウント」**（または「カレンダーアカウント」）をタップします。
4. **「アカウントを追加」** をタップします。
5. 最下部の **「その他」** を選択します。
6. **「照会するカレンダーを追加」** をタップします。
7. **「サーバー」** 欄にコピーした上記のURL（`https://...`）を貼り付け、右上の **「次へ」** をタップします。
8. 設定画面が表示されます：
   - **説明**: 任意の名称を入力（例: `鹿島アントラーズ 試合日程`）
   - **ユーザー名 / パスワード**: 空欄のままでOK
   - **SSLを使用**: オン
   - **更新頻度**: 自動 または 毎日推奨
9. 右上の **「保存」** をタップして完了です！

## 💻 Mac / Googleカレンダーでの登録手順

### Mac（カレンダー.app）
1. 「カレンダー」アプリを起動します。
2. メニューバーの **「ファイル」** > **「新規カレンダー照会...」** をクリックします。
3. コピーした `.ics` のURLを貼り付けて **「照会」** をクリックします。
4. カレンダー名や通知、自動更新頻度（「毎日」推奨）を設定して **「OK」** をクリックします。

### Googleカレンダー（PCブラウザ）
1. PCで [Googleカレンダー](https://calendar.google.com/) を開きます。
2. 左メニューの「他のカレンダー」の横にある **「＋」** > **「URLで追加」** をクリックします。
3. コピーした `.ics` のURLを貼り付け、**「カレンダーを追加」** をクリックします。

## ⚙️ システム構成・アーキテクチャ

```mermaid
flowchart TD
    subgraph Data Sources
        A1[JFA公式サイト<br/>jfa.jp]

    subgraph GitHub Actions [GitHub Actions (毎日 04:00 JST)]
        B1[main.py<br/>日本代表スクレイパー]
        B2[j1_club.py<br/>鹿島アントラーズスクレイパー]
    end

    subgraph Calendars [Generated ICS Files]
        C1[japan_national_team.ics<br/>SAMURAI BLUE 日程]
        C2[j1_club.ics<br/>鹿島アントラーズ 日程]
    end

    subgraph Subscribers [カレンダーアプリ照会]
        D[iPhone / Mac / Google カレンダー]
    end

    A1 -->|HTMLパース| B1
    A2 -->|HTMLパース| B2
    B1 -->|RFC 5545生成| C1
    B2 -->|RFC 5545生成| C2
    C1 -->|Git Commit & Push| D
    C2 -->|Git Commit & Push| D
```

### ファイル構成
```text
jfa-calendar/
├── .github/
│   └── workflows/
│       └── update.yml          # 毎日日本代表・鹿島アントラーズの両方を更新
├── .gitignore
├── japan_national_team.ics      # 日本代表 iCalendarファイル
├── j1_club.ics                 # 鹿島アントラーズ iCalendarファイル
├── main.py                     # 日本代表試合日程取得スクリプト
├── j1_club.py                  # 鹿島アントラーズ試合日程取得スクリプト
├── README.md                   # 利用ガイド・仕様ドキュメント
└── requirements.txt            # Python依存パッケージ
```

- **スクリプト構成**:
  - `main.py`: JFA公式サイトのSAMURAI BLUEページから詳細ページを含めてスクレイピングし、`japan_national_team.ics` を出力。
  - `j1_club.py`: J.League Data Site から鹿島アントラーズ（Team ID: 1）の公式戦日程テーブルをパースし、`j1_club.ics` を出力。
  - どちらのスクリプトもスタンドアロンで実行可能であり、サイト仕様変更時にも互いに影響を与えない疎結合な構成です。
- **ワークフロー (`.github/workflows/update.yml`)**:
  - 毎日定時（UTC 19:00 = JST 04:00）およびファイルプッシュ・手動実行トリガーに対応。
  - 両スクリプトを順次実行し、差分が発生した `.ics` ファイルのみを自動コミット＆プッシュします。

## 🛠️ ローカルでの実行方法（動作確認・開発）

### 1. 仮想環境の準備
```bash
python3 -m venv .venv
source .venv/bin/activate  # Windowsの場合: .venv\Scripts\activate
pip install -r requirements.txt
```

### 2. スクリプトの実行
```bash
# 日本代表カレンダーの更新
python main.py

# 鹿島アントラーズカレンダーの更新
python j1_club.py
```
実行が完了すると、直下に `japan_national_team.ics` および `j1_club.ics` が生成・更新されます。

## 💡 他のJ1/J2/J3クラブへの展開方法

`j1_club.py` は、Jリーグ公式データサイトのクラブ固有ID（`CLUB_TEAM_ID`）を変更するだけで、他のJリーグクラブ用カレンダーとしても簡単に応用可能です。
（例: 浦和レッズ: `3`, 横浜F・マリノス: `5`, 川崎フロンターレ: `21` など）
